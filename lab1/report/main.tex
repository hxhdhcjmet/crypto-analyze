\section{实验目的}

本实验围绕 Enigma 密码机的结构、加密过程和密钥空间展开。通过编程实现给定参数下的 Enigma 加密，理解接线板、转子和反射器在密码变换中的作用；在此基础上分析转子排列、转子起始位置和接线板设置所形成的密钥空间，并结合实际加密速度判断直接穷举攻击的可行性。
